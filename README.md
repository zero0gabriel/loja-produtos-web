# 🛒 Vitrine de Produtos Web

Página de produtos simples e responsiva em HTML, CSS e JavaScript.

## 🚀 Funcionalidades
- 📱 Design responsivo
- 🍔 Menu para telemóveis
- 🛍️ Alerta ao clicar no produto
- ⬆️ Botão voltar ao topo

## ✏️ Como Personalizar
No ficheiro `index.html`:
- **Trocar imagem:** Altera o `src="..."` da tag `<img>`
- **Trocar texto:** Edita o nome em `<h3>` e o preço em `<p class="preco">`

## 🛠️ Tecnologias
HTML5 | CSS3 | JavaScript
